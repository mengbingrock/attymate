# Startup Inputs

Legal Ops Supervisor completes read-only launch intake before implementation child issues are created.

Collect or discover within approved scope:

- User-selected matter and no-cross-matter boundary.
- Workflow type, requested MTC package, autonomy level, approval profile, learning mode, and do-not-learn list.
- Matter root, output root, read-only source roots, forbidden roots, and allowed outputs.
- Subpoena basics: date, issuing party, recipient, categories, compliance date, responses, objections, and production status.
- Meet-and-confer history and deadlines supplied in approved sources.
- Drafting sources: pleadings, exhibits, declarations, example shells, authority tables, and prior approved work product.
- Authority limits: supplied authorities, example-shell authorities, approved external research, or no external research.
- Tool readiness: Codex cwd, Python/OCR runtime, document tooling, browser tooling, connectors, and Firm Operations Guide reference.
- Approval profile, approval gates already approved, and gates still requiring approval.

If any required startup input is missing, batch the question with a recommended default and explain what safe work can continue.
