# Company Packages

Reusable Paperclip company packages live here. Each package follows the markdown-first `agentcompanies/v1` format described in `docs/companies/companies-spec.md`.

## Available Packages

- `california-litigation-legal-team/` - unified legal AI firm for reusable California litigation workflows, including subpoena motion-to-compel work as a workflow under Legal Ops Supervisor.

Packages in this directory must be portable and public-safe. Do not commit local runtime state, credentials, private matter files, firm-specific procedures, account identifiers, or hardcoded machine paths.
