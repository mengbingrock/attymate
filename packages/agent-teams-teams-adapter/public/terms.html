Agent Teams pilot: test use

This app is an internal test of private Teams messaging with the existing distributed Agent Teams framework. Access is limited to explicitly enrolled Microsoft identities and owner-selected devices and connections.

Use the app to check Worker status, request work and test replies. Review actual results. Supported approval requests can be answered in Teams, while secret input and initial operating system permissions require the local owner interface.

Component tests have been performed separately on macOS and Windows. The complete Teams-to-delegated-Windows desktop workflow has not yet passed acceptance testing. Use synthetic data for that validation. This pilot does not establish readiness for a firm-wide rollout and has no payment feature.
